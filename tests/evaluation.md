预期答案：1/3
实际答案：## 计算过程

**问题**：计算定积分 $\int_0^1 x^2 \, dx$

**第一步：求原函数**

由幂函数积分公式：
$$\int x^n \, dx = \frac{x^{n+1}}{n+1}$$

当 $n = 2$ 时，原函数为：
$$F(x) = \frac{x^3}{3}$$

**第二步：应用牛顿-莱布尼茨公式**

$$\int_0^1 x^2 \, dx = F(1) - F(0)$$

**第三步：代入上下限**

- $F(1) = \dfrac{1^3}{3} = \dfrac{1}{3}$
- $F(0) = \dfrac{0^3}{3} = 0$

**第四步：得出结果**

$$\int_0^1 x^2 \, dx = \frac{1}{3} - 0 = \boxed{\frac{1}{3}}$$

**几何意义**：该积分表示曲线 $y = x^2$ 与 x 轴在区间 $[0, 1]$ 上所围成的曲边三角形的面积，其值为 $\dfrac{1}{3}$。

# T8

预期结果：3*x**2*sin(x)+x**3*cos(x)
实际结果：## 求导结果

对 **f(x) = x³·sin(x)** 关于 x 求一阶导数，结果为：

$$f'(x) = x^2\bigl(x\cos(x) + 3\sin(x)\bigr)$$

### 解题过程（乘积法则）

**1. 识别函数形式**

f(x) = x³ · sin(x)，是两个函数 u = x³ 与 v = sin(x) 的乘积。

**2. 应用乘积法则**

若 f = u·v，则 f' = u'·v + u·v'

**3. 分别求导**

- u = x³，则 u' = 3x²
- v = sin(x)，则 v' = cos(x)

**4. 代入公式**

$$f'(x) = 3x^2\sin(x) + x^3\cos(x)$$

**5. 提取公因式 x² 化简**

$$f'(x) = x^2\bigl(3\sin(x) + x\cos(x)\bigr)$$

这与工具计算结果 `x**2*(x*cos(x) + 3*sin(x))` 完全一致。✅

# T9
题目：计算 sin(x)/x 在 x 趋于 0 时的双侧极限
预期结果：1
实际结果：## 计算结果

$$\lim_{x \to 0} \frac{\sin(x)}{x} = 1$$

## 详细说明

这是一个经典的 **0/0 型未定式**极限，双侧极限存在且等于 **1**。

### 方法一：夹逼定理（几何法）

在单位圆中，对 $0 < x < \frac{\pi}{2}$，通过比较三角形、扇形和三角形的面积，可得：

$$\cos(x) < \frac{\sin(x)}{x} < 1$$

当 $x \to 0^+$ 时，$\cos(x) \to 1$，由夹逼定理得右极限为 1。

### 方法二：泰勒展开

将 $\sin(x)$ 展开：

$$\sin(x) = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \cdots$$

两边除以 $x$：

$$\frac{\sin(x)}{x} = 1 - \frac{x^2}{3!} + \frac{x^4}{5!} - \cdots$$

令 $x \to 0$，所有含 $x$ 的项趋于 0，故极限为 **1**。

### 左极限的处理

由于 $\dfrac{\sin(x)}{x}$ 是**偶函数**：

$$\frac{\sin(-x)}{-x} = \frac{-\sin(x)}{-x} = \frac{\sin(x)}{x}$$

因此左极限等于右极限，双侧极限存在。

### 结论

$$\boxed{\lim_{x \to 0} \frac{\sin(x)}{x} = 1}$$

这个极限是微积分中的基础结论，常用于推导 $\sin(x)$ 的导数公式 $(\sin x)' = \cos x$。
是否正确：是

# T12
题目：计算 1/x 在 x 从左侧趋于 0 时的极限
预期结果：-oo
实际结果：## 计算过程与结论

### 1. 单侧极限的定义
\( x \to 0^- \) 表示 \( x \) 取**负值**且无限接近 0，即 \( x < 0 \) 且 \( |x| \) 越来越小。

### 2. 分析符号与绝对值趋势
- **分子**：\( 1 > 0 \)（正数）
- **分母**：\( x < 0 \)（负数），且 \( |x| \to 0^+ \)

因此：
- **符号**：正数 ÷ 负数 = **负数**，所以 \( \frac{1}{x} < 0 \)
- **绝对值**：\( \left|\frac{1}{x}\right| = \frac{1}{|x|} \to +\infty \)（因为分母趋于 0）

### 3. 综合判断
符号为负、绝对值趋于无穷大，因此：

\[
\lim_{x \to 0^-} \frac{1}{x} = -\infty
\]

工具计算结果也验证了这一点：**\(-\infty\)**（即 `-oo`）。

### 4. 关于"极限不存在"的说明
虽然我们写成 \( -\infty \)，但严格来说这个极限**并不存在**（不是有限实数）。这里的 \( -\infty \) 是一种**广义极限**的记号，表示函数值无界地朝负方向发散。

> **对比**：若从右侧趋近（\( x \to 0^+ \)），则 \( \frac{1}{x} \to +\infty \)。左右极限不相等，进一步说明 \( \lim_{x\to 0}\frac{1}{x} \) 作为双侧极限**不存在**。

### 结论
\[
\boxed{\lim_{x \to 0^-} \frac{1}{x} = -\infty}
\]

该极限为无穷大（负无穷），属于极限不存在的情形，表示函数在 \( x=0 \) 左侧无界地趋向负无穷。
是否正确：是

## 1. 先求逐点极限

对固定的 \(x\)，考察

\[
f_n(x)=n^2 x e^{-nx}.
\]

### 当 \(x>0\) 时

令 \(t=nx\to+\infty\)，则

\[
n^2 x e^{-nx}
= \frac{n^2 x}{e^{nx}}
= \frac{n}{x}\cdot \frac{nx}{e^{nx}}
= \frac{n}{x}\cdot \frac{t}{e^{t}}.
\]

由于指数增长 \(e^t\) 远快于多项式 \(t\)，有

\[
\frac{t}{e^t}\to 0.
\]

但这里还有一个因子 \(n/x\to+\infty\)，需要更仔细地看。实际上更直接地：

\[
n^2 x e^{-nx}
= x\cdot \frac{n^2}{e^{nx}}.
\]

对固定 \(x>0\)，\(e^{nx}\) 是指数增长，而 \(n^2\) 是多项式增长，因此

\[
\frac{n^2}{e^{nx}}\to 0.
\]

所以

\[
f_n(x)\to 0,\qquad x>0.
\]

### 当 \(x=0\) 时

\[
f_n(0)=n^2\cdot 0\cdot e^0=0,
\]

所以

\[
f_n(0)\to 0.
\]

因此逐点极限函数为

\[
\boxed{g(x)=\lim_{n\to+\infty} f_n(x)=0,\qquad x\in[0,1].}
\]

---

## 2. 对逐点极限函数积分

如果严格按照题目字面顺序“先求逐点极限，再积分”，则

\[
\int_0^1 g(x)\,dx
= \int_0^1 0\,dx
= \boxed{0}.
\]

这一步与工具结果一致：对函数 \(0\) 在 \([0,1]\) 上积分，结果为 \(0\)。

---

## 3. 重要说明：极限与积分不可交换

虽然逐点极限再积分得到 \(0\)，但必须指出：函数列 \(\{f_n\}\) 在 \([0,1]\) 上并不一致收敛，且

\[
\lim_{n\to+\infty}\int_0^1 f_n(x)\,dx
\neq
\int_0^1 \lim_{n\to+\infty} f_n(x)\,dx.
\]

事实上，先对原函数积分：

\[
\int_0^1 n^2 x e^{-nx}\,dx.
\]

令 \(t=nx\)，则 \(dx=dt/n\)，积分变为

\[
\int_0^n n^2\cdot \frac{t}{n}\cdot e^{-t}\cdot \frac{dt}{n}
= \int_0^n t e^{-t}\,dt.
\]

而

\[
\int_0^n t e^{-t}\,dt
= \left[-(t+1)e^{-t}\right]_0^n
= 1-(n+1)e^{-n}.
\]

因此

\[
\int_0^1 n^2 x e^{-nx}\,dx
= 1-(n+1)e^{-n}.
\]

取极限：

\[
\lim_{n\to+\infty}\int_0^1 f_n(x)\,dx
= \lim_{n\to+\infty}\left(1-(n+1)e^{-n}\right)
= 1.
\]

所以

\[
\boxed{
\lim_{n\to+\infty}\int_0^1 f_n(x)\,dx=1
}
\]

而

\[
\boxed{
\int_0^1 \lim_{n\to+\infty} f_n(x)\,dx=0.
}
\]

两者不相等，说明极限与积分不能交换。

---

## 4. 关于工具结果的说明

- `integrate_function` 给出的“定积分结果为：0”是对极限函数 \(g(x)=0\) 在 \([0,1]\) 上积分的结果，不是对原函数 \(n^2 x e^{-nx}\) 积分的结果。
- 若对原函数积分，结果应为

\[
1-(n+1)e^{-n},
\]

其极限为 \(1\)，不是 \(0\)。

- 极限工具失败提示“Result depends on the sign of -sign(x)”，这主要是因为工具没有区分 \(x>0\)、\(x=0\) 等情形。数学上，对每个固定 \(x\in[0,1]\)，逐点极限都是 \(0\)，因此该工具失败不影响逐点极限结论。

---

## 5. 最终结论

按题目字面要求“先求逐点极限，再积分”，答案为

\]

但必须补充说明：
