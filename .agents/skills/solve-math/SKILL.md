# 数学问题求解

## 工作流程

1. 读懂用户的问题，确定需要数值计算、方程求解、极限、求导、积分还是矩阵运算。当题目包含“先……再……”“然后”或“……之后……”时，必须严格按照用户指定的顺序调用工具；后一个工具必须使用前一个工具的结果作为输入，不得自行交换极限、积分、求导等运算的顺序。
2. 将题目中的数学表达式整理成现有数学 Agent 能处理的输入。
3. 使用 Agent 计算，并查看工具结果和最终检查结果。只要问题涉及已经提供的数学工具，就必须调用对应工具完成计算，不得仅依靠模型自行计算。
涉及极限时必须调用 limit_calculator；
涉及积分时必须调用 integrate_function；
涉及求导时必须调用 differentiate；
涉及方程时必须调用 solve_equation；
涉及矩阵时必须调用 matrix_calculator。
对于“先A，再B”的问题，必须先调用A对应的工具，并把A的 ToolMessage 结果作为B工具的输入。即使模型已经知道答案，也不得跳过工具调用。
4. 向用户说明答案与关键计算步骤；如果现有工具无法完成某一步，说明具体限制。

## 工具调用顺序

- 相互独立的工具可以在同一轮调用。
- 如果后一个操作依赖前一个工具的结果，则每轮只能调用一个工具。
- 必须等待前一个工具返回 ToolMessage 后，才能构造后一个工具的参数。
- 禁止根据模型自行推测的中间结果提前调用后续工具。

## 运行方法

在 `D:\Projects\math-agent` 目录中，使用现有虚拟环境执行 `main.py`，将用户本次的问题作为命令行参数传入。
必须实际执行命令并读取程序输出，再回答用户；不要只向用户展示运行命令，也不要把模型自行计算的结果说成程序结果。

例如：
```powershell
.\.venv\Scripts\python.exe .\main.py "求 x**2 的导数"
```

## 输出格式

工具执行完成后，最终回答统一使用以下格式：

结果：<最终结果>
说明：<最多两句话的必要说明>

规则：

- 默认不输出完整解题过程。
- 不使用 Markdown 标题、加粗符号或 `$$` 数学块。
- 只有用户明确要求“详细步骤”“证明”或“推导过程”时，才展开说明。

## 结果判定

以 `main.py` 输出末尾的最终状态为准，不以运行过程中的计划、工具结果或 Verifier 的中间打印为准。

- 如果末尾显示“检查通过”，根据其后的“最终回答”答复用户。
- 如果末尾显示“检查未通过”，只报告失败原因和“本次没有已验证的答案”；不要引用运行过程中的数值作为已验证答案，也不要声称验证通过。
- 如果命令报错或没有输出最终状态，说明程序未能完成验证。
